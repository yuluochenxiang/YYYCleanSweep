## 一、最终效果

启动时如果目标盘可用空间低于阈值，主窗口顶部栏**下面**出现一条浅黄卡片：

```
┌──────────────────────────────────────────────────────────────────────┐
│ ⚠ C: 盘可用空间只剩 4.3 GB（不足提醒线 5 GB）      [去清理] [知道了] │
└──────────────────────────────────────────────────────────────────────┘
```

- 点「去清理」→ 切到「项目清理」页并停在它上面
- 点「知道了」→ 卡片收起，本次运行不再出现
- 同一天同一个盘**只提示一次**（写进配置，换盘或跨天会重新提醒）
- 空间恢复后不再出现（本来就不触发）

设置页新增一张卡片可以改阈值、关开关、立刻检查一次。

## 二、三个必须先想清楚的设计决策

### 2.1 🔴 绝对不要做后台常驻监控

这是一个**离线小工具**，不是杀毒软件。做成后台监控意味着：

- 常驻一个进程占内存，违背"轻量"定位
- 要处理开机自启、托盘图标、退出逻辑，工作量翻几倍
- 用户还得忍受任务栏里多个图标

所以本卷的范围严格限定为：**只在软件启动时检查一次**。

真正的「定期检查」由 **卷 05 的命令行模式 + Windows 计划任务**组合实现，见 2.3。

### 2.2 展示形式必须是「非模态卡片」，不能用 `QMessageBox`

两个硬原因：

1. `MainWindow.__init__` 末尾有 `QTimer.singleShot(150, lambda: self.start_scan(False))`，
   一上来就在扫描。弹模态框会**把整个界面按住**，用户还没看清就先得点确定。
2. **冒烟测试会卡死**：项目踩过这个坑 ——
   `QMessageBox` 在离屏环境下没人点，进程能挂 15 分钟不退出且没有任何输出。

所以用顶部卡片：来了不打断任何操作，用户想处理就点，不想处理就关掉。

### 2.3 与卷 05（命令行）的分工 —— 这是 F 的完整形态

| 场景 | 谁负责 |
| --- | --- |
| 打开软件时发现快满了 | 本卷（启动即提醒） |
| 每周一早上自动扫一遍并出报告 | 卷 05 + Windows 计划任务 |
| 不在电脑前也能知道 | 计划任务跑 `--json`，报告落盘 |

把这两件事拼起来才是完整的"预警"：

```bat
schtasks /create /tn "YYYCleanSweep 每周扫描" /sc weekly /d MON /st 09:00 ^
  /tr "\"E:\work\WB_\YYYCleanSweep\app\YYYCleanSweepFast\YYYCleanSweepFast.exe\" --scan --json \"E:\reports\weekly.json\" --quiet"
```

> 计划任务一律用**文件夹版**（Fast）：单文件版每次要往 `%TEMP%` 解压约 113 MB。

**如果先做本卷、还没做卷 05**：先把卡片和设置做出来，
并在设置页卡片底部加一行提示文案说明"配合计划任务可定期检查"，
等卷 05 完成后把这条命令补进 README。

## 四、改动清单

### 4.1 `core/config.py` —— 加四个配置键

在 `DEFAULTS` 字典**末尾**（`"dup_keep_dirs": []` 之后）追加：

```python
    # ---- 磁盘空间提醒（提醒只在启动时检查一次，不做后台监控）
    "warn_enabled": True,      # 关了就完全不检查
    "warn_gb": 5,              # 可用空间低于这个值（GB）提醒
    "warn_pct": 3,             # 或低于这个百分比提醒
    "warn_last": "",           # "2026-10-17" —— 同一天同一个盘只提醒一次
```

读取统一走 `self.cfg.get("warn_enabled", True)`。
**不需要写迁移代码** —— `Config.load()` 会自动给老用户补齐新字段（这是它写好的特性）。

### 4.2 `ui/main_window.py` —— 新建提醒卡片（插入点在 `_build()` 里）

现在的布局是：

```python
        outer.addWidget(bar)              # ← 第 493 行：顶部栏
        self.tabs = QTabWidget()          # ← 第 496 行
        ...
        outer.addWidget(self.tabs, 1)     # ← 第 513 行
```

在 **`outer.addWidget(bar)` 之后、`self.tabs = QTabWidget()` 之前**插入：

```python
        # ---- 空间不足提醒：非模态卡片，来了不打断任何操作。
        # （刻意不用 QMessageBox：构造末尾会自动起扫描，模态框会把界面按住，
        #   而且离屏冒烟测试里没人点它，进程能挂住不退出。）
        self.warn_card = QFrame()
        self.warn_card.setObjectName("card")
        self.warn_card.setVisible(False)
        wl = QHBoxLayout(self.warn_card)
        wl.setContentsMargins(14, 8, 14, 8)
        wl.setSpacing(10)
        self.lb_warn = QLabel("")
        self.lb_warn.setObjectName("warn")
        wl.addWidget(self.lb_warn, 1)
        self.btn_warn_clean = QPushButton("去清理")
        self.btn_warn_clean.clicked.connect(self._goto_clean_tab)
        wl.addWidget(self.btn_warn_clean)
        self.btn_warn_ok = QPushButton("知道了")
        self.btn_warn_ok.setObjectName("mini")
        self.btn_warn_ok.clicked.connect(lambda: self.warn_card.setVisible(False))
        wl.addWidget(self.btn_warn_ok)
        outer.addWidget(self.warn_card)
```

三个易错点：

1. `setVisible(False)` **必须在加进布局之前**，否则启动时先闪一下空白卡片。
2. `outer.addWidget(self.warn_card)` 不要给拉伸系数（和 `bar` 一样是自然高度），
   给 `self.tabs, 1` 那个拉伸留给下面的页签区。
3. `lb_warn` 的 `setObjectName("warn")` 需要在 `ui/theme.py` 里有对应样式才生效；
   **样式没配时不会报错**（就是普通文字），先把它做出来，样式可以后补。

### 4.3 检查逻辑（新函数，放在 `_refresh_disk` 后面）

```python
    def _check_disk_space(self, manual=False):
        """启动时的空间提醒。只看目标盘，写完 warn_last 就不再重复打扰。

        manual=True 时忽略「今天已提醒过」，给设置页的「立即检查」按钮用。
        """
        if not self.cfg.get("warn_enabled", True):
            return
        want = (self.drive or "")[:2].upper()
        hit = None
        for letter, total, free in sysinfo.get_drives():
            if letter.upper().startswith(want):
                hit = (letter, total, free)
                break
        if not hit:
            return

        letter, total, free = hit
        gb_line = float(self.cfg.get("warn_gb", 5) or 0) * (1024 ** 3)
        pct_line = float(self.cfg.get("warn_pct", 3) or 0)

        by_gb = gb_line > 0 and free < gb_line
        pct_now = free * 100.0 / max(total, 1)
        by_pct = pct_line > 0 and pct_now < pct_line

        if not (by_gb or by_pct):
            if manual:
                # 手动点「立即检查」却没触发：给一句反馈，2 秒后自己收起
                self.btn_warn_clean.setVisible(False)
                self.lb_warn.setText("当前空间充足")
                self.warn_card.setVisible(True)
                QTimer.singleShot(2000, lambda: self.warn_card.setVisible(False))
            return

        today = time.strftime("%Y-%m-%d")
        last = self.cfg.get("warn_last", "") or ""
        if not manual and last.startswith(today + "|" + letter[:2]):
            return                       # 今天这个盘已经提醒过了
        self.cfg.set("warn_last", today + "|" + letter[:2])

        self.btn_warn_clean.setVisible(True)   # 「当前空间充足」时藏过，这里要恢复
        if by_gb:
            self.lb_warn.setText(
                f"⚠ {letter} 盘可用空间只剩 {fmt(free)}"
                f"（不足提醒线 {fmt(gb_line)}）")
        else:
            self.lb_warn.setText(
                f"⚠ {letter} 盘可用空间只剩 {pct_now:.1f}%"
                f"（不足提醒线 {pct_line:g}%）")
        self.warn_card.setVisible(True)
```

四个细节，漏一个就会出现奇怪现象：

- `warn_last` 的值拼成 `"日期|盘符"`。只记日期的话，用户切到另一个盘检查会被"今天已提醒"误伤。
- GB 和 % **两个都命中时只显示 GB 那条**，别拼成一长串。
- 「当前空间充足」那次会把「去清理」按钮藏起来，所以正常分支里必须 `setVisible(True)` 恢复，
  否则下次真触发了却没有按钮。
- `manual=True` 时**不写** `warn_last`：点一次检查不该把今天的提醒名额用掉。

### 4.4 触发时机

在 `MainWindow.__init__` 里，`QTimer.singleShot(150, ...)` 那一行**下面**再加一行：

```python
        QTimer.singleShot(150, lambda: self.start_scan(False))
        QTimer.singleShot(400, lambda: self._check_disk_space(False))
```

为什么不放在 `__init__` 里直接调：

- `self.drive` 要等 `_build()` 之后才有值
- `self.pal` / 样式要在 `_apply_theme()` 之后
- 延后 400ms 是让用户先看到界面，卡片是"滑出来"的观感而不是"开屏就是黄条"

`time` 已经在文件顶部 import 了吗？**务必确认** —— 没有就在头部补 `import time`。

### 4.5 设置页卡片（加在「缩略图缓存」卡片之后）

照 4.2 那张卡片的写法另抄一份（`QFrame` + `setObjectName("card")` + `QVBoxLayout`），标题 `磁盘空间提醒`：

| 控件 | 类型 | 绑定 |
| --- | --- | --- |
| 复选框 | `QCheckBox("可用空间不足时提醒")` | `self.ck_warn`，`setChecked(...)` 后接 `toggled` |
| GB 输入 | `QSpinBox` range 1–100，后缀 `" GB"` | `self.sp_warn_gb` |
| % 输入 | `QSpinBox` range 1–50，后缀 `" %"` | `self.sp_warn_pct` |
| 按钮 | `QPushButton("立即检查")` | `self._check_disk_space(True)` |

```python
        # 先填值、后接信号 —— 不然启动时就会把配置写一遍
        self.ck_warn.setChecked(bool(self.cfg.get("warn_enabled", True)))
        self.sp_warn_gb.setValue(int(self.cfg.get("warn_gb", 5) or 5))
        self.sp_warn_pct.setValue(int(self.cfg.get("warn_pct", 3) or 3))
        self.ck_warn.toggled.connect(
            lambda v: self.cfg.set("warn_enabled", bool(v)))
        self.sp_warn_gb.valueChanged.connect(
            lambda v: self.cfg.set("warn_gb", int(v)))
        self.sp_warn_pct.valueChanged.connect(
            lambda v: self.cfg.set("warn_pct", int(v)))
```

> 「先填值、后接信号」这条在缩略图缓存那张卡片里有原话注释，是同一个坑，照搬即可。

## 七、常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 卡片永远不出来 | 阈值默认 5 GB 太大 / 目标盘很空 | 临时把 `warn_gb` 设成 1024 强制触发 |
| 启动时闪一下空白卡片 | `setVisible(False)` 写在 addWidget 之后 | 调到前面去 |
| 改 GB 后配置被写成 0 | 先接了信号后填值 | 「先 setValue 后 connect」 |
| 每次启动都提醒很烦 | `warn_last` 没写 / 没拼盘符 | key 格式 `"日期|盘符"`，见 4.3 |
| 冒烟测试挂住不退出 | 手滑用了 `QMessageBox` | 改成 4.3 里的卡片方式 |
| 暗色主题下卡片是白底黑字看不清 | 没套 `card` 的 objectName | 必须是 `QFrame` + `setObjectName("card")` |
| `NameError: name 'time' is not defined` | 文件顶部没 import time | 补上 |
| 离屏断言永远 False | 用了 `isVisible()` | 改用 `not isHidden()` |
