## 二、三个必须先想清楚的设计决策

### 2.1 🔴 编码铁律（本项目踩过两次）

生成的 `.bat` 必须满足：

| 要求 | 值 | 违反后果 |
| --- | --- | --- |
| 编码 | **GBK（ANSI）** | UTF-8 会让中文注释全变乱码 |
| BOM | **不能有** | 带 BOM 时 cmd 解析第一行就整体失败 |
| 换行 | **CRLF** | 纯 LF 会让 `goto` 失效、代码块错乱 |
| 开头 | **禁止 `chcp 65001`** | 这个命令会让批处理当场终止（表现：双击一闪就没） |

Python 里正确写法：

```python
with open(path, "w", encoding="gbk", errors="replace", newline="\r\n") as f:
    f.write(text)
```

> `newline="\r\n"` 是关键：Python 默认会把 `\n` 转成系统换行，Windows 上确实是 `\r\n`，
> 但显式写出来能保证在任何环境都不出错。

### 2.2 为什么不支持「备份后删除」模式

软件内清理有三种模式（回收站 / 备份后删 / 永久删），但**导出只提供前两种里的两种**：
**移到回收站**、**永久删除**。

原因：「备份后删除」需要目标盘路径，而 `robocopy /MOVE` 在不同场景下的行为
（尤其是目标已存在、路径过长）不一致，生成的脚本很容易在用户机器上跑歪。
备份取向的用户应该在界面里做，能用 UI 看进度、能回滚。

### 2.3 为什么 command 类规则要注释掉

`command` 类规则跑的是系统级命令：

```
DISM /Online /Cleanup-Image /StartComponentCleanup
powercfg /h off
vssadmin delete shadows /for=C: /oldest /quiet
```

这些命令**不可逆且耗时长**（DISM 能跑几十分钟）。放进一个用户随手双击的脚本里太危险。

所以：把它们**原样写进脚本但前面加 `REM`**，用户可以自己看懂后决定是否去掉 `REM`。
`manual` 类规则（需要 GUI 操作的项目，如 Docker 数据、虚拟内存迁移）**完全不产出命令**，
只写一行说明。

## 三、改动清单

### 3.1 新建 `core/exporter.py`

```python
"""清理方案导出：把用户勾选好的清理项变成一个可以直接运行的 .bat。

设计三条：
  1. 每条都带中文注释，说明这是什么、风险等级——导出的目的是「让人看懂再执行」，
     不是一个点了就删的黑盒子；
  2. command 类规则（DISM / powercfg / vssadmin 这类系统命令）原样写成 REM 注释，
     默认不自动执行；
  3. 只支持「移到回收站」与「永久删除」两种口径，不支持备份模式（理由见文档）。

⚠️ 编码：必须是 GBK + CRLF 无 BOM，且脚本开头不能出现 chcp 命令。
"""
import os
import time

RECYCLE = "recycle"
PERMANENT = "permanent"

MODE_TITLE = {RECYCLE: "移到回收站", PERMANENT: "永久删除"}

HEAD = """@echo off
REM ============================================================
REM  YYYCleanSweep 清理脚本
REM  生成时间：{now}
REM  处理方式：{mode}
REM  条目数：{n}
REM
REM  用法：右键本文件 -> 以管理员身份运行
REM        本脚本只处理你在软件里勾选过的项目，执行前请再看一遍。
REM ============================================================

net session >nul 2>&1
if %errorlevel% neq 0 (
    echo 提示：当前不是管理员，涉及系统目录的条目会失败。
    echo      建议关闭本窗口后，右键本文件、选择「以管理员身份运行」。
    echo.
)

echo 即将处理以下 {n} 个条目，按任意键开始；想终止请按 Ctrl+C 并输入 N。
pause >nul
echo.
"""

TAIL = """
echo.
echo ============================================================
echo  全部执行完毕。建议回到 YYYCleanSweep 重新扫描确认效果。
echo ============================================================
pause
"""


def _ps_recycle(path, is_dir):
    """一条「移到回收站」的 PowerShell 命令。

    用 .NET 的 FileSystem 方法而不是 Remove-Item：后者删是永久删。
    路径里的单引号要翻倍转义（PowerShell 字符串规则）。
    """
    p = path.replace("'", "''")
    call = ("DeleteDirectory" if is_dir else "DeleteFile")
    return ('powershell -NoProfile -Command "Add-Type -AssemblyName '
            'Microsoft.VisualBasic; [Microsoft.VisualBasic.FileIO.FileSystem]::'
            f"{call}('{p}','OnlyErrorDialogs','SendToRecycleBin')\"")


def _cmd_permanent(path, is_dir):
    """一条永久删除命令。"""
    q = '"%s"' % path
    return ('RD /S /Q %s' % q) if is_dir else ('DEL /F /Q %s' % q)


def _risk_of(rule):
    # 与 core/rules.py 的 RISK_LABEL 保持一致；这里不再引一遍是为了
    # 让 core/exporter.py 保持零依赖、可被命令行模式直接调用
    return {"safe": "安全", "caution": "谨慎", "danger": "危险",
            "migrate": "迁移", "info": "提示"}.get(rule.get("risk"), "—")


def build_bat(pairs, mode=RECYCLE, version=""):
    """生成批处理文本。

    pairs : [(规则 dict, [路径列表])]
    mode  : RECYCLE / PERMANENT
    """
    lines = [HEAD.format(now=time.strftime("%Y-%m-%d %H:%M"),
                         mode=MODE_TITLE.get(mode, mode),
                         n=len(pairs))]
    for i, (rule, paths) in enumerate(pairs, 1):
        name = rule.get("name") or rule.get("id", "")
        m = rule.get("mode")
        lines.append("REM " + "-" * 60)
        lines.append(f"REM [{i}/{len(pairs)}] {name}")
        lines.append(f"REM       规则 id：{rule.get('id','')}"
                     f"    风险：{_risk_of(rule)}")
        if m == "command":
            cmd = (rule.get("command") or "").strip()
            if cmd:
                lines.append("REM       这是系统命令项：已注释，不会自动执行。")
                lines.append("REM       想执行就删掉下面这行开头的 REM")
                for cl in cmd.splitlines():
                    lines.append("REM " + cl)
            else:
                lines.append("REM       条目不完整（规则里没有 command 字段），已跳过")
            lines.append("")
            continue
        if m == "manual":
            lines.append("REM       这一项需要手动在系统设置里操作，不产出任何命令。")
            adv = (rule.get("advice") or "").strip()
            if adv:
                lines.append(f"REM       建议：{adv}")
            lines.append("")
            continue
        if not paths:
            lines.append("REM       这次没有要处理的路径（可能已被白名单拦下）")
            lines.append("")
            continue
        lines.append(f"echo [{i}/{len(pairs)}] {name}")
        for p in paths:
            is_dir = os.path.isdir(p)
            if mode == RECYCLE:
                lines.append(_ps_recycle(p, is_dir))
            else:
                lines.append(_cmd_permanent(p, is_dir))
        lines.append("")
    lines.append(TAIL)
    return "\r\n".join(lines)


def save_bat(pairs, path, mode=RECYCLE, version=""):
    """按 GBK + CRLF 无 BOM 写出。这是本项目踩过两次的坑，不要改编码。"""
    text = build_bat(pairs, mode=mode, version=version)
    with open(path, "w", encoding="gbk", errors="replace", newline="\r\n") as f:
        f.write(text)
    return len(text)
```

```python
    def _selected_plan_for_export(self):
        """[(规则 dict, [路径])] —— 导出脚本专用。

        和 _selected_plan() 的差别：后者要求「必须有要删的路径」，
        会把 command / manual 类规则过滤掉。但导出脚本时恰恰要把它们也列出来
        （command 类写成注释、manual 类只写建议），否则用户勾了 WinSxS
        却导出不了，等于这个功能对最需要它的场景失效。
        """
        out = []
        seen = set()
        for key in sorted(self.checked):
            rid = key.split("|", 1)[0]
            if rid in seen:
                continue
            seen.add(rid)
            r = self.by_id.get(rid)
            if not r or self._rule_protected(r):
                continue
            out.append((r, self._checked_paths(r)))
        return out
```

```python
    # ---------------------------------------------------------- 导出清理脚本（D）
    def _export_script(self):
        """把勾选的项目导出成一个可直接运行的批处理。"""
        from core import exporter
        pairs = self._selected_plan_for_export()
        if not pairs:
            QMessageBox.information(
                self, "没有可导出项",
                "先在左边的清单里勾选要清理的项目，再点导出。")
            return
        modes = [exporter.MODE_TITLE[exporter.RECYCLE],
                 exporter.MODE_TITLE[exporter.PERMANENT]]
        mode_text, ok = QInputDialog.getItem(
            self, "导出清理脚本",
            "脚本用什么方式处理这些条目：", modes, 0, False)
        if not ok or not mode_text:
            return
        mode = (exporter.RECYCLE
                if mode_text == exporter.MODE_TITLE[exporter.RECYCLE]
                else exporter.PERMANENT)
        path, _ = QFileDialog.getSaveFileName(
            self, "导出清理脚本", "清理脚本.bat", "批处理文件 (*.bat)")
        if not path:
            return
        if not path.lower().endswith(".bat"):
            path += ".bat"
        try:
            exporter.save_bat(pairs, path, mode=mode)
        except Exception as e:
            QMessageBox.warning(self, "导出失败", str(e))
            return
        if QMessageBox.question(
                self, "导出完成",
                f"已导出 {len(pairs)} 个清理项到：\n{path}\n\n"
                "现在打开文件夹看看？（先看一遍内容再运行）",
                QMessageBox.Yes | QMessageBox.No) == QMessageBox.Yes:
            self._reveal_file(path, "清理脚本")
```

## 五、常见错误

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| **双击 bat 一闪就没** | 带 BOM / 纯 LF / 开头有 `chcp` | 见 2.1 铁律，用 `encoding="gbk", newline="\r\n"` |
| bat 里中文全是乱码 | 用了 UTF-8 写盘 | 改 `encoding="gbk"` |
| `UnicodeEncodeError` 写盘失败 | 路径里有 GBK 编不出来的字符 | `errors="replace"` 已经在代码里，别删 |
| 导出后啥也没有 | 用 `_selected_plan()` 而不是专用的那个方法 | 用 `_selected_plan_for_export()` |
| command 类规则变成可执行行 | 忘了加 `REM` 前缀 | `_build_bat` 里那段专门处理，别删 |
| 回收站里找不到被删的东西 | 用了 `DEL` / `RD` 当回收站模式 | 回收站模式必须走 PowerShell 的 `SendToRecycleBin` |
| 路径含空格时删错东西 | 命令里路径没加引号 | `cmd /c "& ..."` 里必须是 `'"%s"' % path` |
