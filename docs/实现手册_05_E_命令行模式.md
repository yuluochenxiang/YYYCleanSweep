## 二、四个必须先想清楚的设计决策

### 2.1 🔴 windowed 程序没有控制台（本卷最大的坑，没之一）

**现象**：把上面的命令敲进 cmd，`--version` 一个字都不输出，也不报错，退出码还是 0。

**原因**：两个 spec 文件里都是 `console=False`：

```
YYYCleanSweep.spec:32:      console=False
YYYCleanSweepFast.spec:29:  console=False
```

这种 exe 属于 Windows 子系统，系统**不给它分配控制台**，`sys.stdout` 是 `None`。
Python 的 `print()` 写向 `None` 不会抛异常，只是**什么都不发生** —— 于是看起来像"命令没执行"。

> 这也是为什么不能把 `console` 改成 `True`：那样用户双击 exe 时，
> 每次都会先闪一个黑框出来，对一个图形工具来说是明显的倒退。

**解法**：检测到命令行参数后，自己把控制台挂上来：

1. 父进程（cmd.exe）有控制台 → `AttachConsole(-1)` 借用它的窗口
2. 没有 → `AllocConsole()` 新开一个窗口（**这种情况结束前必须等一下**，见 2.2）

⚠️ 挂上去还不够 —— CRT 的 `stdout` 和 Win32 的句柄是两套东西，
`AllocConsole` 之后必须再走一遍 `GetStdHandle → msvcrt.open_osfhandle → io.open`，
把 Python 的流重新绑到新句柄上，否则照样写不出去。

**实测记录**（2026-10-17，在已有控制台的 Python 进程里验的底层通路）：

| 调用 | 结果 |
| --- | --- |
| `AllocConsole()` | 返回 `0`，`GetLastError=5`（ERROR_ACCESS_DENIED） |
| `SetConsoleOutputCP(65001)` | `1`（成功） |
| `GetStdHandle(-11)` | `0x2b0`（有效句柄） |
| `msvcrt.open_osfhandle(h, O_BINARY)` | fd `3` |
| UTF-8 中文写入 | ✅ 正常 |

> `AllocConsole` 返回 0 是**预期内的**：跑测试的那个 Python 进程本来就有控制台
> （它自己就是在控制台里启动的），再去申请一个自然被拒绝。
> **真正的 windowed exe 里它一定返回非零**，那时才会走到新开窗口这条分支
> —— 别把这个 0 当成 bug。

### 2.2 自己开的窗口，退出前必须停一下

`AllocConsole` 新建的控制台窗口隶属于本进程，**进程一退出窗口立刻消失**。
扫描再漂亮的结果，用户也只看到"黑框一闪"。

所以要用一个全局开关 `_CONSOLE_OWNED` 记住"这次的窗口是我自己开的"，
结束时打一行提示并 `input()` 等回车：

```python
if not _CONSOLE_OWNED:      # 借用了 cmd 的窗口
    return                  # 什么都不做，正常退出
input("按 Enter 关闭窗口…")
```

借来的窗口（`AttachConsole` 成功）**绝对不能这么做** ——
那是用户自己的 cmd 窗口，停在那里等输入会让人以为程序卡死了。

### 2.3 为什么不用「离屏 Qt」跑

项目里确实有 `QT_QPA_PLATFORM=offscreen` 的成熟经验，但命令行模式**不应该**走这条路：

| | 离屏 Qt | 纯 core（本方案） |
| --- | --- | --- |
| 要 import PySide6 | 是（几十 MB 的库） | **否** |
| 要不要构造 MainWindow | 要，还得压住它的自动扫描 | 不需要 |
| 会不会写 GUI 配置 | 会（两边打架） | 不会 |
| 启动耗时（单文件版） | 解压 + 加载 Qt | 几乎立刻 |

判断标尺就一句：**命令行模式的意义之一是「别加载那 47 MB 界面库」，一上来就 `import Qt` 等于白做。**

也因此，`main.py` 里必须**先判断参数、再决定要不要 `import PySide6`**（见 3.2）。

### 2.4 HTML 自己拼，不复用 `ui/report.py`

`ui/report.py` 的 `CleanReportDialog._build_html()` 能力齐全，但它**依赖 Qt 调色板**，
而且导出的是「清理之后」的总结结构（`freed / per_rule / errors`），
和本卷「扫描结果」的结构不是一回事。

按红线 4（core 层不许 import PySide6），这里**重新写一份**约 40 行的内联 CSS 模板。

⚠️ **注入必须用 `.replace`，不能用 `str.format`** —— CSS 里的 `{` `}` 会和占位符打架。
这条 v3.26 踩过，模板里所有占位符一律写成 `__XXX__` 形式。

## 三、改动清单

### 3.1 新建 `core/cli.py`

**已经就在工程里**（约 300 行）。下面是它的完整结构与必须逐字保留的部分。

#### 结构总览

| 函数 | 作用 |
| --- | --- |
| `attach_console()` | 挂控制台 + 重定向标准流（2.1 的解法） |
| `_hold_if_owned()` | 自己开的窗口才等待回车（2.2） |
| `build_parser()` | argparse 参数定义，改这里就等于改命令行接口 |
| `read_version()` | 读版本号（**刻意不 import core.version**，那个带着长文案） |
| `collect_rows(results, min_bytes)` | 把扫描结果摊平、过滤、按体积降序 |
| `run_scan(args)` | 主流程：设盘 → 扫描 → 打印 → 写文件 |
| `_write_json` / `_write_html` | 两种输出 |
| `has_cli_args(argv)` | 给 `main.py` 判断"这次要不要走命令行" |
| `main_cli(argv)` | 命令行入口，返回退出码 |

#### 🔴 必须逐字照抄的一段（`attach_console` 的收尾）

```python
def attach_console():
    global _CONSOLE_OWNED
    import io

    # 已经在真控制台里（从 cmd 跑 python cli.py），什么都不用做
    try:
        if sys.stdout is not None and sys.stdout.fileno() >= 0:
            return True
    except Exception:
        pass

    if os.name != "nt":
        return sys.stdout is not None

    try:
        kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)
        import msvcrt
    except Exception:
        return False

    ATTACH_PARENT_PROCESS = -1
    if not kernel32.AttachConsole(ATTACH_PARENT_PROCESS):
        if not kernel32.AllocConsole():
            return False
        _CONSOLE_OWNED = True          # ← 记住：窗口是我自己开的

    try:                               # 中文输出必须的
        kernel32.SetConsoleOutputCP(65001)
        kernel32.SetConsoleCP(65001)
    except Exception:
        pass

    def _reopen(which, mode):
        const = {"stdin": -10, "stdout": -11, "stderr": -12}[which]
        h = kernel32.GetStdHandle(const)
        if not h or h == ctypes.c_void_p(-1).value:
            return False
        fd = msvcrt.open_osfhandle(h, os.O_BINARY)
        stream = io.open(fd, mode, buffering=1, encoding="utf-8",
                         errors="replace", closefd=True)
        setattr(sys, which, stream)
        return True

    try:
        _reopen("stdout", "w")
        _reopen("stderr", "w")
        try:
            _reopen("stdin", "r")
        except Exception:
            pass
    except Exception:
        # 走不到这里通常说明进程本来就有控制台，按成功处理
        return sys.stdout is not None
    return True
```

几个容易改错的点：

- `sys.stdout.fileno()` 这一步**不能省**：PyInstaller windowed 下有时给的是个没有 fileno 的
  哑对象，不试一下会误判成"有控制台"。
- `ctypes.c_void_p(-1).value` 是 `INVALID_HANDLE_VALUE`，句柄可能是 `ctypes.c_void_p` 也可能是 int，
  两种都要接住。
- `errors="replace"`：扫出来的路径里可能有 GBK 解释不了的字节，让它替换而不是崩溃。

#### 参数表（改这里就等于改接口）

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--scan` | flag | 关 | 执行一次扫描；不带则正常开界面 |
| `--target` | str | 系统盘 | 扫描盘，形如 `C:` / `D:` |
| `--min-size` | str | `0` | 只报告大于该体积的项 |
| `--top` | int | `20` | 控制台显示前 N 条，`0` 表示全部 |
| `--json` | path | 空 | 结果写入 JSON（UTF-8） |
| `--html` | path | 空 | 结果写入自包含 HTML |
| `--quiet` | flag | 关 | 不打印逐条进度 |
| `--version` | flag | 关 | 打印版本号后退出 |

⚠️ `--min-size` 的解析**必须复用 `core/sizefmt.py` 的 `parse_size()`**，不许自己写正则
（它已经支持 `50MB` / `1GB`，并解释了项目中同一套口径）。

#### 退出码约定

| 码 | 含义 |
| --- | --- |
| `0` | 成功 |
| `2` | 参数错误（看不懂 `--min-size`、盘符不存在） |
| `3` | 扫描失败 / 写文件失败 |
| `130` | Ctrl+C 中断 |

> 计划任务里可以根据 `%ERRORLEVEL%` 判断要不要发告警，不做出来就没法接自动化。

#### 已实测的行为

```
has_cli_args([])           -> False
has_cli_args(['--scan'])   -> True
read_version()             -> 3.30
collect_rows 过滤前        -> [微信缓存 3.0 GB, npm 缓存 900 MB, 很小的项 10 KB]
collect_rows >= 1GB        -> [微信缓存 3.0 GB]           ← error 项被自动丢弃
_write_json                -> True（740 字节，回读 3 条）
_write_html                -> True（2203 字节，**占位符残留 0 个**）
parse_size('50MB')         -> 52428800.0
```

> 「占位符残留 0 个」这一项**必须自己验一遍**：用 `"__" in html_text` 检查。
> 少 replace 一个，`__ROWS__` 就会原样显示给用户看。

### 3.2 改 `ui/main.py` —— 加命令行分支

现在是全文：

```python
"""YYYCleanSweep 磁盘清理工具 离线版 —— 入口。完全离线，无任何网络请求。"""
import os
import sys

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))

from PySide6.QtWidgets import QApplication

from ui.main_window import MainWindow
from ui.theme import THEMES
from core.version import APP_NAME


def main():
    """程序入口：起 Qt、套主题、开主窗口。全程不联网。"""
    app = QApplication(sys.argv)
    app.setApplicationName(APP_NAME)
    app.setStyleSheet(THEMES["light"])

    win = MainWindow()
    win.show()
    sys.exit(app.exec())


if __name__ == "__main__":
    main()
```

**整段替换成**（注意 import 的位置，它就是成败关键）：

```python
"""YYYCleanSweep 磁盘清理工具 离线版 —— 入口。完全离线，无任何网络请求。"""
import os
import sys

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))


def main():
    """程序入口。

    先看有没有命令行参数：有的话走无界面扫描分支，连 PySide6 都不加载
    （命令行的意义之一就是别把这几十 MB 的界面库拖起来）。
    没有参数才是正常开窗口。全程不联网。
    """
    from core.cli import has_cli_args, main_cli

    if has_cli_args():
        sys.exit(main_cli())

    from PySide6.QtWidgets import QApplication

    from ui.main_window import MainWindow
    from ui.theme import THEMES
    from core.version import APP_NAME

    app = QApplication(sys.argv)
    app.setApplicationName(APP_NAME)
    app.setStyleSheet(THEMES["light"])

    win = MainWindow()
    win.show()
    sys.exit(app.exec())


if __name__ == "__main__":
    main()
```

三个必须守的点：

1. **顶层的 `from PySide6.QtWidgets import QApplication` 必须挪进函数体**。
   留在模块顶层的话，命令行模式一 import main 就把 Qt 拖起来了，白做。
2. `from core.cli import ...` 放在函数里也一样，保持 `__main__` 之外不触发副作用。
3. `sys.path.insert(...)` 那行留在最上面（PyInstaller 打包后 `core` 的位置靠它找）。

### 3.3 不需要改的地方（别多此一举）

## 六、常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 命令跑完一个字都没有 | windowed 没有控制台 | 检查 `main_cli` 第一行是不是调了 `attach_console()` |
| 挂了控制台还是不输出 | 没把 CRT 的 stdout 重新绑到新句柄 | 必须有 `_reopen()` 那一步，`AllocConsole` 本身不够 |
| 中文变问号 / 报错 | 没设 UTF-8 代码页 | `SetConsoleOutputCP(65001)`，且 `io.open(...,encoding="utf-8")` |
| 从 cmd 跑完卡住不动 | 把借来的窗口当成自己开的 | `_CONSOLE_OWNED` 只在 `AllocConsole` 那条分支里置 True |
| 双击 exe 变出一闪而过的黑框 | 改了 spec 的 `console=False` | 改回去 |
| HTML 页面里出现 `__ROWS__` | 少了一行 `.replace` | 用 `"__" in 内容` 自检 |
| 加了参数但界面还是打开了 | `has_cli_args()` 没识别 | 它只认 `--scan / --version / -h / --help`，加了新参数要同步补进去 |
| 报 `Missing optional dependency` 之类的 Qt 错 | `import Qt` 写在顶层了 | 按 3.2 挪进 `main()` 函数体 |
| 计划任务里路径带空格失效 | bat 没加引号 | 整个 exe 路径外层加英文双引号 |
