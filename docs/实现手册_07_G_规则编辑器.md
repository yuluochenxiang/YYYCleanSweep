## 二、四个必须先想清楚的设计决策

### 2.1 只写「用户可编辑副本」，绝不写打包时嵌进去的默认规则

`core/rules.py` 已经有一条现成的机制：

```python
def _external_rules_dir():
    """exe 旁边的 rules 目录（用户可直接编辑）。"""
    if getattr(sys, "frozen", False):
        return os.path.join(os.path.dirname(sys.executable), "rules")
    return _bundled_rules_dir()
```

所以本卷**不需要自己发明 Config 之外的存储**：读写的目标路径就是 `_rules_path()`
（它内部已经是"优先 exe 旁，首次运行自动释放一份默认"）。

⚠️ 由此带来一个必须写进文档的坑 —— **发版会覆盖用户改过的规则**：

> `build.py` 在 v3.20 之后会把工程里的 `rules\*.json`
> **覆盖同步到 `app\rules\`**（不同步的话新版内嵌知识库永远不生效）。
> 所以用户自己在 `app\rules\` 里改的东西，**下次打包会被冲掉**。
> 本卷保存时必须提示用户「建议同步备份」，并且「备份当前」按钮要能随手导出一份。

### 2.2 🔴 写坏了程序会起不来 —— 必须有兜底

编辑器最后写出的是一个 JSON。只要出现半个字符的错（比如路径里没转义的反斜杠），
下次启动 `load_rules()` 直接抛异常，界面连打开的机会都没有。

三重保险，**缺一不可**：

| 保险 | 做法 |
| --- | --- |
| 保存前自动备份 | 覆盖前先写一份带时间戳的 `.bak` |
| 写盘用原子替换 | 先写 `.tmp` 再 `os.replace`，写一半断电不会留半个文件 |
| 「恢复内置默认」按钮 | 从 `_bundled_rules_dir()` 直接拷回来，一键救活 |

另外**必须做校验**（见 4.1 的 `validate`），校验不通过就不许保存，
而不是"先让他存了崩了再说"。

### 2.3 下拉选项必须从代码派生，不许手写对照表

这条是 v3.27 修过的教训（当时手写了一份风险权重文案表，结果和真实取值脱节）。

- `risk` → 来自 `core/rules.py` 的 `RISK_ORDER` / `RISK_LABEL`（现成的，直接 import）
- `category` → 来自 json 里读出来的 `categories` 列表
- `mode` → 目前 `core/rules.py` **没有**常量，需要在 4.2 里新增一个 `MODE_LABEL`

### 2.4 core 层不许碰 Qt

按红线 4：读写、校验、备份、恢复这些**纯逻辑**放 `core/ruleedit.py`（不 import PySide6）；
只有对话框本体放 `ui/rule_editor.py`。好处是这些函数能被命令行或测试脚本直接调用。

### 4.1 新建 `core/ruleedit.py`（纯逻辑，不许 import PySide6）

```python
"""清理规则的读写、校验、备份与恢复。

刻意不碰 Qt：这些函数要能被界面和测试脚本共用。
写盘一律「先写 .tmp 再 os.replace」，与 core/config.py、core/paths.py 保持一致。
"""
import json
import os
import shutil
import time

from . import rules as R


def path_of():
    """当前实际生效的规则文件路径（exe 旁优先，没有就用内置的）。"""
    return R._rules_path()


def load_raw():
    """读完整 json（含 categories / version / updated），不做字段补齐。"""
    with open(path_of(), "r", encoding="utf-8") as f:
        return json.load(f)


def save_raw(data):
    """原子写盘。返回 True / False，失败原因由调用方提示。"""
    p = path_of()
    d = os.path.dirname(p)
    os.makedirs(d, exist_ok=True)
    tmp = p + ".tmp"
    with open(tmp, "w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2)
    os.replace(tmp, p)
    return True


def backup(tag=""):
    """保存前先备份一份带时间戳的副本，返回备份文件路径。"""
    src = path_of()
    if not os.path.exists(src):
        return ""
    name = os.path.basename(src).rsplit(".", 1)[0]
    stamp = time.strftime("%Y%m%d_%H%M%S")
    dst = os.path.join(os.path.dirname(src),
                       f"{name}_{stamp}{tag}.bak")
    shutil.copy2(src, dst)
    return dst


def list_backups(limit=20):
    """列出历史备份，新的在前。"""
    d = os.path.dirname(path_of())
    if not os.path.isdir(d):
        return []
    base = os.path.basename(path_of()).rsplit(".", 1)[0]
    items = [os.path.join(d, n) for n in os.listdir(d)
             if n.startswith(base) and n.endswith(".bak")]
    items.sort(key=os.path.getmtime, reverse=True)
    return items[:limit]


def restore(backup_path):
    """从某个备份恢复。"""
    shutil.copy2(backup_path, path_of())
    return True


def restore_builtin():
    """恢复出厂规则：从打包目录里那份拷贝回来。用户改过的东西会丢失，
    所以调用方必须先弹出二次确认。"""
    src = os.path.join(R._bundled_rules_dir(), "clean_rules.json")
    if not os.path.exists(src):
        return False
    shutil.copy2(src, path_of())
    return True


def validate(data):
    """校验，返回错误字符串列表。空列表 = 没问题。

    这里宁可严一点也不放行 —— 写坏 json 会导致下次启动直接崩，
    校验是最后一道关。
    """
    errs = []
    if not isinstance(data, dict):
        return ["文件格式不是 JSON 对象"]
    cats = data.get("categories")
    rules = data.get("rules")
    if not isinstance(cats, list) or not isinstance(rules, list):
        return ["categories / rules 必须是数组"]

    cat_ids = set()
    for i, c in enumerate(cats):
        cid = c.get("id")
        if not cid:
            errs.append(f"分类 #{i + 1} 缺少 id")
        elif cid in cat_ids:
            errs.append(f"分类 id 重复：{cid}")
        cat_ids.add(cid)

    seen = set()
    for i, r in enumerate(rules):
        tag = f"第 {i + 1} 条"
        rid = (r.get("id") or "").strip()
        if not rid:
            errs.append(f"{tag}：缺少 id")
        elif rid in seen:
            errs.append(f"{tag}：id 重复（{rid}）")
        seen.add(rid)
        if not (r.get("name") or "").strip():
            errs.append(f"{tag}（{rid or '无 id'}）：缺少名称")
        c = r.get("category")
        if c not in cat_ids:
            errs.append(f"{tag}（{rid}）：category「{c}」不在分类列表里")
        if r.get("risk") not in R.RISK_ORDER:
            errs.append(f"{tag}（{rid}）：risk「{r.get('risk')}」取值不合法")
        if r.get("mode") not in R.MODE_LABEL:
            errs.append(f"{tag}（{rid}）：mode「{r.get('mode')}」取值不合法")
        if not isinstance(r.get("paths"), list):
            errs.append(f"{tag}（{rid}）：paths 必须是数组")
        r_level = r.get("admin", False)
        if not isinstance(r_level, bool):
            errs.append(f"{tag}（{rid}）：admin 必须是 true / false")
    return errs
```

### 4.3 新建 `ui/rule_editor.py`

一个 `RuleEditorDialog(QDialog)`。要点：

- **上半**：`QTableWidget`，7 列（id / 名称 / 分类 / 方式 / 风险 / 管理员 / 路径）
- **下拉三列用委托**（手写对照表会脱节，见 2.3）：

```python
class _ComboDelegate(QStyledItemDelegate):
    """给某一列挂下拉框。options: [(值, 显示文本), ...]"""

    def __init__(self, options, parent=None):
        super().__init__(parent)
        self.options = options

    def createEditor(self, parent, option, index):
        cb = QComboBox(parent)
        for val, label in self.options:
            cb.addItem(label, val)
        return cb

    def setEditorData(self, editor, index):
        v = index.data(Qt.UserRole) or index.data(Qt.EditRole)
        i = editor.findData(v)
        editor.setCurrentIndex(i if i >= 0 else 0)

    def setModelData(self, editor, model, index):
        model.setData(index, editor.currentData(), Qt.EditRole)
        model.setData(index, editor.currentText(), Qt.DisplayRole)

    def updateEditorGeometry(self, editor, option, index):
        editor.setGeometry(option.rect)
```

挂上去（单元格 UserRole 存真实值，DisplayRole 存中文）：

```python
cats = [(c["id"], c["name"]) for c in data["categories"]]
t.setItemDelegateForColumn(2, _ComboDelegate(cats, t))
t.setItemDelegateForColumn(3, _ComboDelegate(
    [(k, v) for k, v in R.MODE_LABEL.items()], t))
t.setItemDelegateForColumn(4, _ComboDelegate(
    [(k, v) for k, v in R.RISK_LABEL.items()], t))
```

- **路径列**：单元格里显示 `;` 连接（`Windows` 路径不含分号，可以安全 split），
  取回时 `[p.strip() for p in text.split(";") if p.strip()]`。
  超过 2 条时 tooltip 显示完整列表。
- **下半**：选中行时把 `desc / advice / operation / recovery` 填进四个 `QPlainTextEdit`，
  编辑失焦（`focusOutEvent`）或切换选中行时写回内存里的 dict。
  ⚠️ **切换选中前必须先落回内存**，否则改了没保存就换行，内容会丢。
- **按钮**：
  - `新增` → 追加一条 id 为 `my_rule_N` 的空规则
  - `复制选中` → 深拷贝选中行，id 加后缀 `_copy`
  - `删除` → 从列表移除（**不二次确认**，因为没保存都不算数）
  - `保存` → `backup()` → `validate()` → 有错就弹 `规则有误，未保存` + 列出错误，否则 `save_raw()` 关闭
  - `备份当前` → `backup()` 后提示文件路径
  - `恢复内置默认` → **必须二次确认**（`QMessageBox.question`），确认后 `restore_builtin()`
- 搜索框：按 id / 名称 / 路径过滤行（`setRowHidden`），不是重建表格。

## 七、常见错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 保存后主界面没变 | 没调 `_reload_rules()` | 对话框返回 Accepted 时必须重载 |
| 下一次启动直接崩 | 写出了不合法 json | `validate()` 必须先过；且 `json.dump` 用 `ensure_ascii=False` + utf-8 |
| 中文全是 `\uXXXX` | 忘了 `ensure_ascii=False` | 写 json 一律带上 |
| 下拉项比实际少 | 手写对照表 / 漏了某个 mode | 按 2.3 从 `RISK_LABEL` `MODE_LABEL` 派生 |
| 改了说明没生效 | 换行时内容没落回内存 | 切换选中前先写回 dict（见 4.3 的 ⚠️） |
| 用户改的规则下次打包没了 | `build.py` 会覆盖 `app\rules\` | 见 2.1，文档必须提示用户「备份当前」 |
| 恢复内置默认没反应 | `_bundled_rules_dir()` 路径不对 | 打包态走 `_MEIPASS` / `_internal`，别自己拼 |
| 表格里路径看不到全 | 列太窄 | 塞进 tooltip，`lb_rule_path` 那边的做法同理 |
