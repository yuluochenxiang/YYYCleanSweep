# YYYCleanSweep 扩展实现手册 · 00 总纲

> **这份文档是给「实现者」看的，不是给决策者看的。**
> 每一卷都按「照着做就能实现」的标准写，假设实现者没读过本项目任何一行代码。
>
> **使用方式**（很重要，照做能省钱）：
> 1. **先让 AI 读本文件（00 总纲）**，让它知道项目全貌和红线。
> 2. **再让它读对应的某一卷**（如 `实现手册_01_B_空间快照.md`），一次只读一卷。
> 3. 一次只做一卷。做完、验收通过、版本升好，再给下一卷。
> 4. 不要把 00~09 全部一次性塞进上下文 —— 便宜的 AI 会顾此失彼，反而做错更多。

## 三、六条红线（违反任何一条都要返工）

### 红线 1：不许引入第三方库
只能用 Python 标准库 + PySide6。
Pillow / numpy / opencv / requests / send2trash（已在白名单，仅 cleaner 用）之外一律不许。
**原因**：包体现在是 49 MB，几乎全是 PySide6，引入这些库会立刻涨 3~30 MB。

### 红线 2：界面文案逐字照抄
文档里给的每个按钮文字、标签、提示语都要**一字不改**。
不许「优化」「扩写」「补全」，不许把「相似查找」写成「相似图片查重」。

### 红线 3：不许顺手重构
看到重复代码、觉得某写法不好——**不许动**。
只改文档要求的地方。想重构先问用户。

### 红线 4：core 层不许 import PySide6
（唯一例外：`core/thumbs.py` 原本就依赖 Qt 的 QImage。）

### 红线 5：改完必须跑通验证三部曲
见第五节。**不许跳过**。

### 红线 6：不许动 `.gitignore` 里排除的东西
`app/`、`venv/`、`_shot/`、`*.exe`、`*.zip` 都不进仓库。

### 已知的两个离屏陷阱（踩过，别再踩）

1. **`MainWindow.__init__` 里有 `QTimer.singleShot(150, start_scan)` 会自动开扫**，
   会把你注入的假 `w.results` 清空。
   做离线校验时，构造完立刻加一行：
   ```python
   w.start_scan = lambda *a, **k: None
   ```
2. **窗口没 `show()` 时子控件的 `isVisible()` 恒为 False**。
   要判断某控件有没有显示，用 `isHidden()` 取反，不能用 `isVisible()`。

## 九、常见报错对照表

| 报错 / 现象 | 原因 | 处理 |
| --- | --- | --- |
| `ModuleNotFoundError: PySide6` | 用了系统 Python | 换 `E:\work\WB_\YYYCleanSweep\venv\Scripts\python.exe` |
| 双击 bat 一闪就没 | bat 是 LF 换行 / 含 `chcp 65001` / 带 UTF-8 BOM | 生成的 bat 必须 **GBK 无 BOM + CRLF**，见卷四 |
| `sqlite3.OperationalError: no such column` | 加了字段但没重建表 | SQLite 用 `DROP TABLE` 重建，或写 `ALTER TABLE ADD COLUMN` 并在 `_ensure_schema` 里调用 |
| 界面亮色主题下列表还是暗块 | 新控件在 `_apply_theme()` 之前创建 | 在 `on_theme(self, theme)` 里也要刷新新控件 |
| 加列后表格错位 | 忘了同步 `FirstColFit` 的 `others` 字典 / `SectionResizeMode` | 见卷二（它有完整的加列检查清单） |
| `libshiboken: QApplication already deleted` | 一个进程建了两个 `QApplication` | `QApplication` 是单例，一个进程只建一次 |
| 冒烟测试卡住不退出 | 有模态框（如 `QMessageBox`）在等输入 | 测试前把 `QMessageBox.information` 打桩 |
