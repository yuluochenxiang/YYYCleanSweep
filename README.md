# YYYCleanSweep 磁盘清理工具 离线版 `v3.41`

Windows 离线磁盘清理与空间分析工具。单文件/文件夹两种形态，**全程无网络请求**，
  
扫描前先告诉你每一项占多大、是什么、能不能删，再让你决定。

Python 3.13 + PySide6 写成，规则和目录知识库全部是可编辑的 JSON。

### 最近更新（v3.39）

- **去重页多了第四种「判定方式」：相似查找（仅图片，看内容）**。前三种找的是「字节一模一样」的重复，这一种找的是「看起来是同一张图」——原图、发过微信被压过的、导小了一号的，都能凑成一组。算法是感知哈希（dHash），对 **缩放**、**转发重压缩** 特别有效，实测同一张照片缩到 256px 距离 0、JPEG 压到质量 35 距离 2~3；两张完全无关的图距离 20 上下，离任何一档阈值都远，所以默认就敢给「严格」档。
- **相似度三档可调**：`严格`（几乎同一张图，默认）/ `标准`（同一张图的明显改版）/ `宽松`（构图相近即算，误判多）。只在你选了「相似查找」时这两个控件才露面，平时不占地方。
- **⚠️ 它对裁剪很敏感，这点必须先说清**：dHash 比的是相邻像素差，裁掉一点边，整行的对应关系就错位了——实测裁掉 5% 边缘，距离能从 0 跳到 16，等于「找不到」。所以页面上一行灰字直接写明：*相似查找对「缩放、转发压缩」效果最好；裁剪或旋转过的图可能找不到。* 这不是 bug，是这类算法的固有局限。
- **相似组默认一张都不勾**。这是刻意留的底线：dHash 只说「像」，不说「一样」，万一判断错了（两张不同的合影恰好构图相近），程序替你把其中一张勾上就是真删照片。所以相似组只给建议、不替你决定，要靠你自己看一眼再勾。同理，组行「可释放」在你没勾之前写的是 `待选择` 而不是 `0 B`。
- **`这组不是重复`**：右键分组行可以整组忽略，记进配置，下次扫描不再打扰。
- **排除规则默认全开**：`.ico` / `.svg` 矢量图、边长 < 128px 的表情头像、> 6000px 的扫描件全景图、以及 `C://Windows//Web` 这类系统自带壁纸目录，一律不参与比对。相似查找也**不看「大于 N MB」**——照片常常只有几百 KB，按文件大小筛会把真实照片全漏掉，这一路改成按像素尺寸筛。
- **数量再大也不卡**：五千张图两两比是 1250 万次，聚类前先用位切片分桶筛候选；同一张图的上千份副本也做了特殊处理，不会因为「段值太常见」被整体跳过。

### 最近更新（v3.38）

- **大文件定位页能直接看压缩包里装了什么**：选中 `.zip / .whl / .jar / .tar / .tar.gz / .tgz / .tar.xz / .tar.bz2` 时，右侧会多出一块「压缩包内容」——`共 412 个成员 · 解压后 3.8 GB · 压缩率 68%`，下面是按类型画的条形图（视频/图片/文档…配色与「类型构成」同源），最后一行指出最大的那个成员叫什么、多大。目的很实在：不必解压就知道这个包该不该删。
- **只读清单，不解压、不落盘**：zip 读中央目录、tar 流式过一遍（超过 800 MB 的大包直接跳过并说明原因），最多统计 20000 个成员，加密成员只做标记不去碰内容。`.rar / .7z / .tar.Z` 读不了，会明确写「暂不支持 .rar 格式」而不是假装读到了。
- **顺手修了个老 bug**：类型构成条形图此前整根画成纯黑——`hex_alpha()` 返回的是 QSS 用的 `rgba(...)` 字符串，直接塞进 `QColor()` 解析失败，画刷静默退化成黑色。新增 `with_alpha()` 返回真正的 `QColor`，条形图和勾选框悬停态都恢复成本来的配色。

### 最近更新（v3.37）

- **不用改 JSON 了，界面里就能改清理规则**：设置页新增「清理规则」卡片（会显示当前生效的文件路径与总条数），点 **编辑规则** 打开表格编辑器。7 列一览 `id / 名称 / 分类 / 方式 / 风险 / 管理员 / 路径`，其中分类、方式、风险三列是下拉选择，选项直接从程序里的真实取值派生，不会填出程序不认的值；选中一行可以在下面补 `说明 / 建议 / 执行 / 恢复`；顶部按分类筛、按 id·名称·路径搜；`新增 / 复制选中 / 删除` 随手加减。保存后**主窗口立刻重新加载并重扫**，不用重启。
- **写坏了也能救回来**：保存前自动备份一份带时间戳的 `.bak`，并先跑一轮校验——id 重复、分类不存在、风险/方式取值不认识、`paths` 不是数组，一律拦下不写盘，错误逐条列出来给你看。真改糟了还有 `恢复内置默认`（有二次确认）或直接拿 `.bak` 覆盖回去。
- **一句提醒**：自己改过的规则记得点 `备份当前` 留一份——打包新版时工程里的 `rules\*.json` 会覆盖同步到 `app\rules\`，这是为了让内嵌知识库的更新能生效，不是 bug。

### 最近更新（v3.36）

- **磁盘快满时，打开软件先提醒一句**：可用空间低于提醒线时，顶栏下面会出现一条浅黄提示条——`⚠ C: 盘可用空间只剩 7.6 GB（不足提醒线 10 GB）`，右边两个按钮：**去清理**（跳到项目清理页）和 **知道了**（收起）。它**不是弹窗**，不会按住界面、也不打断正在进行的扫描。提醒线可以按 GB 也可以按百分比，两个都设了就只显示更直观的那条 GB 文案。
- **提醒频率可自选**：默认「每天一次」（同一个盘当天已经提醒过就不再打扰，换盘或跨天会重新提醒），也可以切成「每次启动」；不想要就在设置页把开关关掉。设置页新增「磁盘空间提醒」卡片：开关、两个阈值输入框、频率下拉、以及一个 **立即检查**（当场按当前阈值查一次，没触发会显示「当前空间充足」并自动收起）。
- **说清楚它不常驻**：这个提醒**只在启动程序时查一次**，不占后台内存、不加托盘图标、不做开机自启。想「每周一自动查」请用上一版的命令行模式配 Windows 计划任务，两件事拼起来才算完整预警。

### 最近更新（v3.35）

- **加了命令行模式，可以挂计划任务了**：带参数运行就不开窗口，直接扫一次并输出结果——`--scan` 打印表格，`--json` / `--html` 写报告，`--min-size` / `--top` 控粒度，`--quiet` 只留汇总。**不带任何参数双击还是正常开界面**，不会闪黑框。退出码分 4 种（0 成功 / 2 参数错误 / 3 扫描失败 / 130 已中断），计划任务能据此判断要不要发告警。这条分支**完全不加载界面库**：先看参数、再决定要不要起 Qt，所以在老机器上定时跑不会多拖几十 MB。
- 一个坑值得写下来：exe 是 `console=False` 打包的（否则双击会闪黑框），这种进程 `sys.stdout` 是 `None`，`print()` 不报错但**什么都不输出**。所以命令行分支会先给自己挂上控制台（借用父窗口，没有就新开一个），并把标准流重新绑到新句柄上——中文按 UTF-8 输出，不乱码。

### 最近更新（v3.34）

- **新增「导出清理脚本」**：项目清理页底部多了一个**导出清理脚本**按钮。在清单里勾好项目后点它，选「移到回收站」或「永久删除」，就把这一整套清理方案存成一个 `.bat`——可以拿去右键「以管理员身份运行」，也可以丢进计划任务做定期清理。每条前面都带中文注释（第几条、规则名、风险等级），开头有管理员检测与「按任意键开始」确认。**默认不碰系统命令类**：DISM、`powercfg` 这类条目只写成 `REM` 注释，想执行得自己删掉行首的 REM；需要手动操作的项目只写建议、不产出命令。文件按 GBK + CRLF 无 BOM 写出（这条踩过两次坑，改成 UTF-8 或出现 `chcp` 都会「双击一闪就没」）。

### 最近更新（v3.33）

- **新增「重复文件夹」页**：找的是整棵被复制过去的目录树，而不是单个重复文件。用 Merkle 签名做精确判定（文件结构逐层一致才算同一份），再用「大小 + 文件数 + 顶层名字重合率」找出高度相似的项目副本（比如 `proj-v1` / `proj-v2`）。结果分「完全相同」和「大部分相同」两块，「可释放」按「留一份、删其余」计算。默认跳过 `node_modules` 与虚拟环境（可关）；最低占用和重合率都可调。

### 最近更新（v3.32）

### 最近更新（v3.28）

- **大文件定位可以只扫一个文件夹了**：以前这一页只能选整块盘，机械盘 / 大容量盘扫一遍太慢。现在顶部改成 **「扫描位置」**，多出 **「浏览」** 按钮，可以直接挑任意目录（下拉里也顺带列出 下载 / 桌面 / 文档 / 视频 / 图片 等常用位置），**只扫需要的文件夹**。扫描内核本来就支持任意目录，之前只是界面把目标类型锁死成了「盘」。

## 二、九个页签

1. **顶栏「目标」** — 位置固定在标题右边，但**每个页面各自记住自己的目标**：
   
   项目清理记盘、目录分析记目录（可浏览）、大文件定位记目录、文件夹去重记目录，互不覆盖；
   
   切到没有目标的页（文件去重 / 系统信息 / 系统瘦身 / 我的标记 / 设置）整块隐藏。
2. **项目清理** — 左侧分类、中间清单、右侧详情，三栏标题同一字号字重；
   
   **点表头即可排序**（占用按真实字节、风险按「越该动手越靠前」，再点一次反向）。
   
   「应用缓存」分类收录了 AppData 里的空间大户：豆包、B 站、剪映、WPS、
   
   微信内置浏览器，以及跨软件的 `Cache` / `Code Cache` / `GPUCache` 通配扫描
   
   （把各软件藏起来的缓存一次性找出来）。
   
   一条规则对应多个目录时左侧有**三角**可展开成子项，可以只勾其中一部分
   
   （比如只清 Chrome 缓存、保留 Edge 的登录状态）；
   
   「展开子目录」按钮可一次全部展开。**右键任意一行**可直接打开目录、
   
   复制完整路径、加入/移出白名单、勾选/取消、预览或只清这一项。
3. **目录分析** — 扫描位置取自顶栏「目标」（本页独立记忆），逐层显示占用；
   
   每个目录标注**作用与处置建议**；
   
   顶栏「方块图」按钮可切到 **Treemap 视图**（面积 = 占用，一眼看出谁最大，
   
   双击下钻、右键复用同一套菜单）。
   
   方块图有三种**配色模式**（顶栏「配色」按钮轮换，底部图例说明颜色含义）：
   
   **按文件类型**（这块被视频/图片/代码/游戏资源哪一类吃掉，参考 WizTree）、
   
   **按子文件夹**（同一子目录及其下层共用一个色系）、
   
   **按风险**（可清理绿 / 谨慎黄 / 危险红）。文字颜色按底色亮度自动取黑或白，
   
   对比度始终 ≥ 4.5:1，不会出现「字和底色糊在一起」；
   
   右侧是「环形占比 + 指标 + 类型构成条形图」的卡片流，鼠标停在哪一行
   
   就弹出那一行的完整说明（含作用、建议、最近修改）。
   
   对目录的**标记按钮组摆在底部通用操作条**上（白名单 / 可清理 / 写备注 /
   
   清除标记 / 打开位置 / 深入扫描），和清理页、文件去重页位置一致；
   
   **右键结果行**同样能直接打标记，不用先选中再去底部点按钮。
4. **大文件定位** — 找出大于 N MB 的文件，按目录树分组展示，**只报告不删除**；
   
   右侧同步显示选中项的占比环形图与类型构成；
   
   选中 `.zip / .whl / .jar / .tar / .tar.gz` 时还会列出**压缩包内容**
   
   （成员数、解压后体积、压缩率、按类型构成、最大成员），不解压也能判断该不该删。
   
   **右键结果行**可打开文件 / 在资源管理器中显示 / 复制路径或文件名 / 展开下级。
5. **文件夹去重** — 找**整棵被复制过去的目录树**（整个项目文件夹被复制一份、
   
   照片库被导入两次这类），按目录算指纹：文件结构完全一致才算「完全相同」，
   
   另有「重合率 ≥ 80%」的近似组可调。每行直接写明**可释放多少**（留一份、删其余），
   
   不会重复统计父子目录造成的同一份冗余。`node_modules` / `venv` 这类噪音目录
   
   默认跳过（可取消）。**右键**可打开位置、复制路径、展开当前组。
6. **文件去重** — 在两个目录（可以填同一个）之间按**大小**（可选首末 64KB 快速校验
   
   或完整 MD5）找文件去重，按保留规则每组自动留一个、其余标记删除，
   
   可移到回收站 / 备份后删除 / 永久删除。判定方式还有第四种 **相似查找**：
   
   只对图片，按「看起来是不是同一张」聚类（缩放、转发压缩过的图都能认出来），
   
   三档相似度可调，**相似组默认一张都不勾**，要你自己看过再决定。
   
   保留规则里**优先保留目录**最高优先：组里只要有文件在你标过的目录下就一定留它，
   
   其次才是创建时间 / 修改时间 / 路径长短。
7. **系统信息** — 管理员状态、各分区剩余、页面文件配置、休眠占用，
   
   附带打开虚拟内存 / 存储感知设置的入口。
8. **系统瘦身** — 把原来「系统信息」里只能看的项目做成可操作项：休眠文件、
   
   页面文件、系统还原点、Windows 更新缓存、WinSxS 组件存储、临时文件、回收站。
   
   后台统计各自占用（统一带单位，数字下还有占比条）；风险列用**分级彩色文本**
   
   （可清理绿 / 谨慎黄 / 高风险红，与「项目清理」页同一套配色）。
   
   表格里不放「一点就开始清理」的按钮：选中一行 → 底部操作条显示**将要对谁、
   
   做什么、执行什么命令** → 点执行 → 再确认一次；「复制命令」可把实际命令
   
   复制出来自己核对。操作一律走 Windows 自带命令（powercfg / vssadmin /
   
   Dism / net）与系统 API，**需要管理员的会弹 UAC 提权**，程序不会自动改系统设置。
9. **我的标记** — 统一管理所有白名单与备注，可编辑、删除、跳转；
   
   **右键一行**即可改成白名单 / 可清理，或删掉这条标记。
10. **设置与历史** — 主题、默认扫描盘、**音效开关与音量**、配置导出导入；
    
    扫描缓存 / 缩略图缓存 / 空间快照的占用与清理，磁盘空间提醒的阈值与频率，
    清理规则的图形化编辑；
    
    历史操作可一键复用当时的选择；清理日志可打开查看。
    
    设置项较多，**整页可上下滚动**，窗口压矮也不会截掉下面的卡片。

**全站统一的「点表头排序」**（`ui/widgets.py: HeaderSorter`）：项目清理、目录分析、
  
大文件定位、文件去重、我的标记、历史记录、系统瘦身，七个列表都能点表头排序。
  
容量列按**真实字节**排（不是 "1.2 GB" < "900 MB" 这种字符串序），
  
占比重按百分比、时间按时间戳、风险/权限/处置按自定义权重；
  
树只重排**同级兄弟**，父子关系、勾选状态、展开状态、悬浮提示全部保留，
  
也不会打断目录分析页的懒加载展开。

## 三、配色与可读性

- **亮色主题**：白底上的次级文字按 WCAG 实测校准过 —— 正文 16.4:1、
    
  次级 8.7:1、提示小字 5.2:1、选中字/选中底 7.1:1，全部 ≥ 4.5:1（AA）。
    
  选中态用同一族的深蓝字 + 实一点的浅蓝底，不再发灰发飘。
- **暗色主题**：默认主题，卡片式深灰 + 蓝色强调色。
- 方块图（Treemap）的文字颜色按底色亮度自动取黑/白，同样 ≥ 4.5:1。

## 四、安全设计

- **默认回收站**：删除走 `send2trash`，误删可从回收站还原。
- **备份模式**：选「备份到其他盘」，文件被 `move` 到目标盘，日志里记录 `源路径 -> 目标路径`。
- **白名单**：把目录标记为白名单后，目录分析里绿色高亮，清理时自动跳过并弹窗说明。
- **危险项二次确认**：涉及「危险」级别会先弹警告。
- **手动类不代劳**：微信数据、Windows\Installer、驱动库这类只给操作指引，程序不会替你删。
- **操作日志**：每次清理动过的路径都追加写入 `clean_history.log`，误删后可逐条回溯。

## 五、运行

### 文件夹版（推荐日常用）

```
YYYCleanSweepFast\YYYCleanSweepFast.exe
```

免解压，`1.8 秒`启动。

### 单文件便携版

```
YYYCleanSweep.exe        （46 MB，双击即用）
```

> ⚠️ 单文件版每次启动会把约 113 MB 解压到 `%TEMP%\_MEI*`。
>   
> 如果装了火绒/360 等带实时监控的杀软，会逐个扫描这些释放出来的 dll，
>   
> **启动可能要几十秒**。本机日常使用请用文件夹版；
>   
> 单文件版适合拷到没有 Python 环境的机器上应急。

### 命令行扫描（无界面，可挂计划任务）

同一个 exe，带上参数就不开窗口，直接跑一次扫描并输出结果：

```bat
YYYCleanSweep.exe --version
YYYCleanSweep.exe --scan
YYYCleanSweep.exe --scan --target D: --min-size 50MB --top 0
YYYCleanSweep.exe --scan --json C:\reports\clean.json
YYYCleanSweep.exe --scan --html C:\reports\clean.html --quiet
```

| 参数 | 说明 |
| --- | --- |
| `--scan` | 执行一次扫描（不带任何参数则正常打开界面） |
| `--target` | 扫描盘，形如 `C:` / `D:`，默认系统盘 |
| `--min-size` | 只报告大于该体积的项，如 `50MB` / `1GB` |
| `--top` | 控制台只显示前 N 条，`0` 表示全部（默认 20） |
| `--json` / `--html` | 结果写成 JSON（UTF-8）或自包含网页报告 |
| `--quiet` | 不打印逐条进度，只出汇总 |
| `--version` | 打印版本号后退出 |

退出码：`0` 成功 / `2` 参数错误 / `3` 扫描失败 / `130` 已中断。
计划任务里可以据此判断要不要发告警：

```bat
"E:\work\WB_\YYYCleanSweep\app\YYYCleanSweepFast\YYYCleanSweepFast.exe" ^
  --scan --json "E:\reports\%date:~0,4%%date:~5,2%%date:~8,2%.json" --quiet
```

> 定时任务**请用文件夹版（Fast）**：单文件版每次启动都要往 `%TEMP%` 解压约 113 MB。
>   
> 命令行分支**完全不加载界面库**（判断参数在前、`import PySide6` 在后），
> 所以在老机器上跑计划任务不会额外拖几十 MB 的 Qt。

直接建成计划任务（每周一 09:00 扫一遍，结果落盘）：

```bat

  /tr "\"E:\work\WB_\YYYCleanSweep\app\YYYCleanSweepFast\YYYCleanSweepFast.exe\" --scan --json \"E:\reports\weekly.json\" --quiet"
```

## 六、自定义规则（不用改代码）

程序首次启动会在 exe 旁生成 `rules\` 目录，三个 JSON 都可以直接编辑，**重启即生效**：

| 文件                   | 内容                          | 条目数  |
| -------------------- | --------------------------- | ---- |
| `clean_rules.json`   | 清理规则：路径、风险、说明、建议、操作方式、恢复方式  | 80   |
| `dir_knowledge.json` | 目录作用知识库：这个目录是什么、能不能删、建议怎么处理 | 428  |
| `file_types.json`    | 扩展名归类（视频/图片/日志/AI模型…共 15 类） | 15 类 |

### 在界面里改（v3.37 起，不用手写 JSON）

**设置与历史 → 清理规则 → 编辑规则**，打开的是一个表格编辑器：

- 7 列一览：`id / 名称 / 分类 / 方式 / 风险 / 管理员 / 路径`，分类、方式、风险三列是下拉选择，选项直接从代码里的真实取值派生，不会出现"填了个程序不认的值"；
- 选中一行后，下面四个框可以补 `说明 / 建议 / 执行 / 恢复`；
- 顶部能按分类筛、按 id·名称·路径搜；`新增 / 复制选中 / 删除` 随手加减；
- **保存前会自动备份**一份带时间戳的 `.bak` 到 `rules\` 目录，并先做一轮校验（id 重复、分类不存在、风险/方式取值不认识、paths 不是数组…）——校验不过就不写盘，对话框会把问题逐条列出来；
- 改糟了有两条退路：`恢复内置默认`（回出厂规则，有二次确认）和直接拿 `.bak` 覆盖回去。

> ⚠️ **自己改过的规则请留一份备份**（按钮 `备份当前` 就是干这个的）：
> 打包新版时会把工程里的 `rules\*.json` 覆盖同步到 `app\rules\`，
> 你自己改的内容会被冲掉。这是为了让内嵌的知识库更新能生效，不是 bug。

### 加一条清理规则（手写 JSON 的老办法，仍然有效）

```json
{
  "id": "my_app_cache",
  "category": "app",
  "name": "某某软件缓存",
  "risk": "safe",
  "mode": "clear_contents",
  "paths": ["%LOCALAPPDATA%\\MyApp\\Cache"],
  "desc": "某某软件运行时产生的缓存。",
  "advice": "可以放心清理，下次启动会重建。",
  "recovery": "删了会自动重建，无需恢复。",
  "admin": false
}
```

`mode` 可选：`clear_contents`（清空目录内容）/ `delete_dir`（删整个目录）/
  
`delete_files`（按 `patterns` 删匹配文件）/ `glob_dirs`（批量匹配目录）/
  
`command`（执行系统命令）/ `manual`（只给指引，不执行）。

### 加一条目录说明

```json
{
  "id": "my_dir",
  "name": "我的工程目录",
  "kind": "user",
  "risk": "keep",
  "paths": ["D:\\myproject"],
  "purpose": "我自己在用的工程目录，里面有源码和构建产物。",
  "advice": "不要删；build 目录可以清，会重新生成。"
}
```


`risk` 可选：`safe`（可清理）/ `caution`（谨慎）/ `danger`（别动）/
  
`migrate`（建议迁移）/ `keep`（建议保留）。
  
匹配优先级：完整路径尾部 > 父目录+目录名 > 目录名 > 路径中段 > 关键词。
  
没收录的目录会按「位置 + 名称 + 文件构成」兜底推断，并在详情里标注「知识库未收录」。

## 九、重新打包

**最省事的一条路**：双击 `build.bat`（或 `python build.py`）。它会按 `core/version.py`
里的版本号建 `E:\work\WB_\YYYCleanSweep_<版本>\`，依次构建 onefile 与 onedir，
把工程里的 `rules\*.json` 同步到 `app\rules\`，再把旧 `Fast` 目录改名备份后部署。
只构建不部署用 `python build.py --no-deploy`。

手动打包也仍然可以——工程已内置两份 spec（数据文件已写进 `datas`，无需手敲 `--add-data`）：

```bash
# 文件夹版（推荐日常用，启动快）
pyinstaller YYYCleanSweepFast.spec --noconfirm --distpath=_fastout --workpath=_fastbuild

# 单文件便携版（双击即用，启动较慢）
pyinstaller YYYCleanSweep.spec --noconfirm --distpath=_oneout --workpath=_onebuild
```

> 用独立 `--distpath`/`--workpath` 是为了绕开本机对默认输出目录的大批量删除保护。
>   
> 产物分别在 `_fastout/YYYCleanSweepFast/` 与 `_oneout/YYYCleanSweep.exe`。

> 单文件版强杀进程会在 `%TEMP%` 留下 `_MEI*` 解压目录（每个 113 MB），
>   
> 正常退出会自动清理。发现 C 盘莫名瘦身可以检查这个目录。

## 十、界面表现的几个约定

这几条是刻意统一过的，改代码时别破坏：

- **选中态只有一种**：所有列表 / 树 / 表格共用 `RowDelegate` 自绘
    
  （圆角背景 + 左侧 3px 强调色条）。以前靠 QSS `border-left` 实现，
    
  一选中文字就会右移 3px，而且各控件观感不一致。
- **三角一律自绘**：`QSS` 里**不能出现** `QTreeWidget::branch`、
    
  `QComboBox::drop-down`、`QSpinBox::up-arrow` 这类子控件规则——
    
  只要写了，`QStyleSheetStyle` 就自己接管那一格的绘制，不再把
    
  `PE_IndicatorBranch` / `PE_IndicatorArrowDown` / `PE_IndicatorSpinUp`
    
  转发给底层样式，自绘三角就画不出来（表现为"没有箭头"）。
    
  所以展开三角（▶ 折叠 / ▼ 展开）、下拉框三角、微调框上下三角全部由
    
  `BigCheckStyle` 统一画；叶子节点画一条淡引导线。
    
  树的顶层必须 `setRootIsDecorated(True)`（统一走 `setup_tree()`），
    
  否则多目录规则根本没有展开入口。
- **容量口径统一**：`core/sizefmt.py` 一个函数管全部，界面、清理器、日志都调它；
    
  悬浮提示里另外给精确字节数。
- **层级靠字号区分**：树的顶层加粗并大 1pt，子层常规；页签选中项 14px 加粗。
- **图表优先于文字**：右侧详情一律「环形图 + 指标 + 条形图」，
    
  被精简掉的列全部收进鼠标悬浮提示。
- **扫描中表现统一**：五个会扫描的页（项目清理 / 目录分析 / 大文件定位 /
    
  文件夹去重 / 文件去重）共用同一个 `ui/busy.py::ScanBanner`，位置也都在**底部操作条下面**：
    
  左侧旋转指示器、主副文案、已用秒数、停止按钮，底边一条条纹进度条
    
  （知道总量时走实心进度，不知道总量时走流动条纹）。
- **右键优先**：所有结果行都能右键，且右键菜单的音效按条目级别区分——
    
  「打开位置」是打开音、「加入白名单」是确认音、「删除标记」是警告音。
- **音效分级**：`core/sound.py` 现场合成正弦波 → `%APPDATA%\YYYCleanSweep\sfx\*.wav`，
    
  用 `winsound` 异步播放；六个级别（主操作 / 危险 / 正向 / 导航 / 勾选 / 普通点击）
    
  按控件 `objectName` 自动选音，详见 `ui/sound.py::BTN_LEVELS`。
    
  不打包音频文件、不引入 QtMultimedia。

### 右侧区域方案选型（调研过 GitHub 上的同类实现）

| 方案                  | 代表项目                                                          | 优点               | 结论                    |
| ------------------- | ------------------------------------------------------------- | ---------------- | --------------------- |
| 树形表 + 右侧详情面板        | QDirStat、WizTree                                              | 精确、能定位到具体文件      | **保留为本工具主形态**         |
| Squarified Treemap  | QDirStat `TreemapTile`、WinDirStat、`laserson/squarify`(Python) | 一眼看出"谁最大"        | 后续可加为可切换视图            |
| Sunburst 环形分层       | SquirrelDisk、Space Radar、Baobab                               | 层级关系直观、可点击下钻     | 适合做"占比"，本工具用简化版 Donut |
| Icicle / Flamegraph | Space Radar                                                   | 比 sunburst 更易读标签 | 备选                    |
| 类型构成条形图             | QDirStat MIME 分类                                              | 回答"是什么类型占了空间"    | **已实现**（TypeBars）     |
| 悬浮提示补信息             | DaisyDisk                                                     | 不占横向空间           | **已实现**（行 tooltip）    |

也就是说：目前采用「树表 + 环形占比 + 类型条形图 + 悬浮提示」这一组合，
  
是把 QDirStat 的详情面板、DaisyDisk 的悬浮提示、SquirrelDisk 的环形图
  
拆出最容易落地的部分拼起来的；真正的 treemap 视图留作后续可选项。

## 十一、已知边界

- 非系统盘的「项目清理」天然偏少（多数缓存在系统盘）。
    
  切盘后会提示改用**目录分析**或**大文件定位**，这两个页对任意盘都完整有效。
- 目录分析是分层扫描，深度没到底的目录显示 `≥`，点「深入扫描」可再往下挖 3 层。
- 占用中的文件删不掉（Temp 里常见），会记在日志里，不影响其它条目。
- **相似查找认不出裁剪或旋转过的图**：dHash 比的是相邻像素差，裁掉 5% 边缘距离就会
    
  从 0 跳到 16。缩放、转发压缩完全没问题；裁过、转过、加了很大面积水印的图，
    
  多半找不到——这不是判断阈值的问题，换「宽松」档也一样。
- 自己建的个人目录知识库没收录时会走兜底推断，想让它认得就往
    
  `dir_knowledge.json` 里加一条。
